# Kayros CRM — Telegram Bot

Отдельный модуль бота. Работает независимо от веб-сервера, подключается к той же базе данных.

## Установка

```bash
cd bot
pip install -r requirements.txt
```

## Настройка

1. Откройте CRM → **Настройки** (вкладка Telegram-бот)
2. Вставьте токен от [@BotFather](https://t.me/BotFather)
3. Вставьте API-ключ DeepSeek с [platform.deepseek.com](https://platform.deepseek.com)
4. Заполните системный промпт (описание вашего сервиса)

## Запуск

```bash
# Из папки bot/
python main.py

# Или из корня проекта
python bot/main.py
```

## Возможности

- 💰 **Цены** — поиск по прайсу из базы данных CRM
- 📅 **Запись** — пошаговый диалог, запись сохраняется в CRM → Записи
- 📞 **Контакты** — адрес, телефон, часы работы из настроек
- 💬 **ИИ-ассистент** — DeepSeek отвечает на свободные вопросы с учётом вашего прайса

## Архитектура

```
bot/
├── main.py          # Точка входа, регистрация хендлеров
├── django_setup.py  # Инициализация Django ORM
├── db.py            # Работа с базой данных
├── ai.py            # Интеграция с DeepSeek API
├── requirements.txt
└── handlers/
    ├── start.py     # /start и главное меню
    ├── prices.py    # Поиск цен
    ├── booking.py   # Запись на ремонт
    └── chat.py      # Свободный чат и контакты
```

Бот читает из БД: настройки сайта, прайс-лист, и пишет записи (Appointment).
Все остальные данные CRM не затрагивает.
