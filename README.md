# Kayros CRM

CRM-система для сервисного центра по ремонту смартфонов.  
Включает публичный сайт, панель управления и Telegram-бота.

---

## Возможности

### Публичный сайт
- Главная страница с описанием услуг и формой обратной связи
- Каталог цен на ремонт (подтягивается из базы)
- Страница «О нас» с картой и юридической информацией
- Страница контактов с реквизитами компании

### CRM (панель управления)
- **Заказы** — приём, статусы, история, назначение мастера, оплата
- **Клиенты** — база клиентов, история заказов, привязка Telegram
- **Записи** — заявки с сайта и из Telegram-бота, конвертация в заказ
- **Склад** — запчасти, аксессуары, движения, поставщики
- **Продажи** — продажа аксессуаров без ремонта
- **Финансы** — расходы, зарплата, штрафы с уведомлениями, аналитика
- **Сотрудники** — роли, уведомления, задачи
- **Прайс** — бренды, модели устройств, виды работ, цены
- **Документы** — печать актов, гарантийных талонов, товарных чеков
- **Настройки** — все данные компании, карты, реквизиты, токен бота

### Telegram-бот
- При первом запуске запрашивает контакт → клиент сохраняется в CRM
- Поиск цен по модели или виду работы
- Запись на ремонт (пошаговый диалог, запись попадает в CRM)
- Свободный чат с ИИ-ассистентом (DeepSeek или локальная модель)

## Быстрый старт

### 1. Виртуальное окружение и зависимости

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux / Mac
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Файл настроек

```bash
cp .env.example .env
```

Минимальная конфигурация для разработки — открыть `.env` и поставить:

```env
SECRET_KEY=любой-длинный-случайный-ключ
DEBUG=True
USE_SQLITE=True
```

### 3. База данных

```bash
python manage.py migrate
```

### 4. Тестовые данные (опционально)

```bash
python manage.py seed_data
```

Создаёт: бренды, модели, прайс, сотрудников, клиентов, 40 заказов.  
Логин: `admin` / Пароль: `admin123`

### 5. Запуск

```bash
# Только сайт
python manage.py runserver

# Сайт + Telegram-бот одновременно
python run.py

# Только бот
python run.py --bot-only

# Другой порт
python run.py --port 8080
```

**Сайт:** http://127.0.0.1:8000  
**CRM:** http://127.0.0.1:8000/crm/

## Telegram-бот

### Настройка

1. Создать бота через [@BotFather](https://t.me/BotFather), получить токен
2. Открыть **CRM → Настройки → Telegram-бот**
3. Вставить токен бота
4. (Опционально) Вставить DeepSeek API Key — [platform.deepseek.com](https://platform.deepseek.com)
5. Заполнить системный промпт — описание вашего сервисного центра

### Локальная модель вместо API

Если не хочется платить за API — можно запустить модель локально через [Ollama](https://ollama.com):

```bash
# Установить Ollama: https://ollama.com
ollama pull deepseek-r1:7b
```

Затем в **CRM → Настройки → Telegram-бот**:
- Ollama URL: `http://localhost:11434/v1`
- Модель: `deepseek-r1:7b`

| Модель | Размер | Минимум RAM |
|--------|--------|-------------|
| `deepseek-r1:1.5b` | 1.5 ГБ | 4 ГБ |
| `deepseek-r1:7b` | 5 ГБ | 8 ГБ |
| `deepseek-r1:14b` | 9 ГБ | 16 ГБ |

## Управление базой данных

```bash
# Заполнить тестовыми данными
python manage.py seed_data

# Очистить данные (пользователи и настройки сохраняются)
python manage.py clear_db

# Очистить всё
python manage.py clear_db --all

# Без подтверждения
python manage.py clear_db --yes
```

│   ├── db.py                 # Работа с общей БД через Django ORM
│   ├── ai.py                 # DeepSeek API / Ollama
│   ├── django_setup.py       # Инициализация Django вне веб-сервера
│   └── handlers/
│       ├── start.py          # /start, регистрация клиента
│       ├── booking.py        # Запись на ремонт
│       ├── prices.py         # Поиск цен
│       └── chat.py           # ИИ-ассистент, контакты

    └── crm/                  # Шаблоны CRM

Бот использует ту же базу данных, что и сайт, через Django ORM.  
Папку `bot/` можно удалить — сайт продолжит работать без изменений.

## Настройки компании

Всё что отображается на сайте, в боте и на документах — настраивается в **CRM → Настройки**:

- Название, телефон, адрес, часы работы
- Текст «О нас», встраиваемая карта (Яндекс / Google)
- ИНН, ОГРН, КПП, директор, юридический адрес
- Банк, БИК, расчётный и корреспондентский счета
- Email, WhatsApp, Telegram, сайт
- Логотип и печать (используются в документах)
- Токен бота, DeepSeek API Key, системный промпт ИИ

Изменения применяются мгновенно — на сайте, в боте и во всех печатных документах.

## Продакшн

Перед деплоем:

1. Поменять `SECRET_KEY` на длинный случайный
2. Установить `DEBUG=False`
3. Прописать `ALLOWED_HOSTS=ваш-домен.ru`
4. Настроить PostgreSQL (`USE_SQLITE=False` + параметры БД)
5. Запустить Redis
6. Выполнить `python manage.py collectstatic`
