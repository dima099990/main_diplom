# Kayros CRM

CRM-система для сервисного центра по ремонту смартфонов.  
Включает публичный сайт, панель управления и Telegram-бота с ИИ-ассистентом.

---

## Возможности

### Публичный сайт
- Главная страница с описанием услуг и формой обратной связи
- Каталог цен на ремонт (из базы данных)
- Страница «О нас» с юридической информацией и картой
- Страница контактов с реквизитами компании

### CRM (панель управления)
- **Заказы** — приём, статусы, история, назначение мастера, оплата
- **Клиенты** — база клиентов, история заказов, привязка Telegram
- **Записи** — заявки с сайта и из Telegram-бота, конвертация в заказ, полное редактирование
- **Склад** — запчасти, аксессуары, движения, поставщики
- **Продажи** — продажа аксессуаров без ремонта
- **Финансы** — расходы, зарплата, штрафы с уведомлениями, аналитика
- **Сотрудники** — роли, уведомления, задачи
- **Прайс** — бренды, модели устройств, виды работ, цены
- **Документы** — печать актов, гарантийных талонов, товарных чеков
- **Настройки** — все данные компании, карты, реквизиты, токен бота

### Зарплата (динамический расчёт)
- Бонус за ремонты и продажи считается из реальных данных × **текущий** процент
- Изменение процента сотрудника сразу отражается в расчёте
- Оклад, премии и штрафы — ручные записи администратора
- Администратор видит зарплаты всех сотрудников за текущий месяц

### Telegram-бот
- При первом запуске запрашивает контакт → клиент сохраняется в CRM
- Поиск цен по модели или виду работы
- Запись на ремонт (пошаговый диалог, запись попадает в CRM)
- Свободный чат с ИИ-ассистентом (DeepSeek API или Ollama локально)

## Быстрый старт

### 1. Виртуальное окружение и зависимости

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux / Mac
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Файл настроек

```bash
cp .env.example .env
```

Минимальная конфигурация для разработки — открыть `.env` и поставить:

```env
SECRET_KEY=любой-длинный-случайный-ключ
DEBUG=True
USE_SQLITE=True
```

### 3. База данных

```bash
python manage.py migrate
```

### 4. Тестовые данные (опционально)

```bash
python manage.py seed_data
```

Создаёт: бренды, модели, прайс, сотрудников, клиентов, 40 заказов.  
Логин: `admin` / Пароль: `admin123`

### 5. Запуск

```bash
# Сайт + бот
python run.py

# Сайт + бот + Ollama (локальный ИИ)
python run.py --ollama

# Только сайт
python run.py --site-only

# Только бот
python run.py --bot-only

# Доступен снаружи (на сервере)
python run.py --host 0.0.0.0 --port 8000

# Сайт + бот + Ollama на сервере
python run.py --host 0.0.0.0 --port 8000 --ollama
```

**Сайт:** http://127.0.0.1:8000  
**CRM:** http://127.0.0.1:8000/crm/

## Telegram-бот

### Настройка

1. Создать бота через [@BotFather](https://t.me/BotFather), получить токен
2. Открыть **CRM → Настройки → Telegram-бот**
3. Вставить токен бота
4. Выбрать ИИ-бэкенд (см. ниже)
5. Заполнить системный промпт — описание вашего сервисного центра

### Вариант 1 — DeepSeek API (облако)

Зарегистрироваться на [platform.deepseek.com](https://platform.deepseek.com), пополнить баланс, скопировать API Key.

В **CRM → Настройки → Telegram-бот**:
- DeepSeek API Key: `sk-...`
- Ollama URL: **оставить пустым**

### Вариант 2 — Ollama (локально, бесплатно)

```bash
# 1. Установить Ollama: https://ollama.com
# 2. Скачать модель
ollama pull deepseek-r1:1.5b   # лёгкая, ~1.5 ГБ
ollama pull deepseek-r1:7b     # лучше качество, ~5 ГБ
```

В **CRM → Настройки → Telegram-бот**:
- Ollama URL: `http://localhost:11434/v1`
- Модель: `deepseek-r1:1.5b`
- DeepSeek API Key: **очистить** (иначе приоритет у DeepSeek)

Запуск всего одной командой (Ollama стартует автоматически):
```bash
python run.py --ollama
```

| Модель | Размер | Мин. RAM |
|--------|--------|----------|
| `deepseek-r1:1.5b` | 1.5 ГБ | 4 ГБ |
| `deepseek-r1:7b` | 5 ГБ | 8 ГБ |
| `deepseek-r1:14b` | 9 ГБ | 16 ГБ |

> Приоритет: если заполнен DeepSeek API Key → используется DeepSeek.  
> Если только Ollama URL → используется Ollama.

## Управление базой данных

```bash
# Заполнить тестовыми данными
python manage.py seed_data

# Очистить транзакционные данные (заказы, клиенты, склад...)
python manage.py clear_db

# Очистить всё включая справочники и пользователей
python manage.py clear_db --all

# Без подтверждения
python manage.py clear_db --yes
```

## Роли пользователей

| Роль | Доступ |
|------|--------|
| `admin` | Всё: настройки, зарплаты всех сотрудников, штрафы, аналитика |
| `manager` | Заказы, клиенты, склад, продажи, задачи |
| `employee` | Свои заказы, свои задачи, своя зарплата |

Роль назначается в **CRM → Сотрудники → редактировать**.

## Настройки компании

Всё что отображается на сайте, в боте и на документах — настраивается в **CRM → Настройки**:

- Название, телефон, адрес, часы работы
- Текст «О нас», встраиваемая карта (Яндекс / Google)
- ИНН, ОГРН, КПП, директор, юридический адрес
- Банк, БИК, расчётный и корреспондентский счета
- Email, WhatsApp, Telegram, сайт
- Логотип и печать (используются в документах)
- Токен бота, DeepSeek API Key / Ollama URL, системный промпт ИИ

Изменения применяются мгновенно — на сайте, в боте и во всех печатных документах.

## Продакшн

Перед деплоем:

1. Поменять `SECRET_KEY` на длинный случайный
2. Установить `DEBUG=False`
3. Прописать `ALLOWED_HOSTS=ваш-домен.ru`
4. Настроить PostgreSQL (`USE_SQLITE=False` + параметры БД в `.env`)
5. Запустить Redis
6. Выполнить `python manage.py collectstatic`
7. Запустить через `python run.py --host 0.0.0.0 --port 8000`
